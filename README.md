# 2MOV — райдшеринг без 30% комиссии агрегатора

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![GitFlic](https://img.shields.io/badge/GitFlic-Open%20Source-blue)](https://gitflic.ru/piroman99/2mov)

**2MOV** — это открытая платформа для для городской мобильности, такси и курьерских услуг, работающая через ботов в **MAX** и **Telegram**.

Мы не агрегатор. Мы информационный сервис, который напрямую связывает заказчиков и исполнителей. Комиссия — **0–8%** вместо 30% у монополистов.

---

## 🎯 Возможности

| Функция | Описание |
|---------|----------|
| 🚕 **Курьерские заказы** | Доставка от А до Б с параметрами груза (вес, габариты, хрупкость) |
| ⭐ **Рейтинг и отзывы** | Честная система оценок. Влияет на приоритет заказов |
| 🔐 **Код подтверждения** | Безопасная передача груза. Только после кода заказ считается выполненным |
| 💬 **MAX + Telegram** | Работает в обоих мессенджерах. В MAX и Telegram. В планах приложения |
| 📦 **Аукцион** | Водители конкурируют ценой. Заказчик выбирает лучшее предложение |
| 🔓 **Открытый код** | Весь код на GitFlic. Можете проверить, форкнуть, улучшить |

## 🏗️ Технологический стек

| Компонент | Технология |
|-----------|------------|
| Язык | **Go 1.21+** |
| База данных | **MongoDB** |
| Веб-сервер | **Caddy** (автоматический SSL) |
| Боты | MAX (MAX api) + Telegram (go-telegram-bot-api) |
| Контейнеризация | **Docker + Docker Compose** |
| Репозиторий | **GitFlic** (российский GitHub) |

---
## 🏗️ Архитектура

Проект состоит из двух серверов:

- **Сервер А (РФ)**: MAX-бот, MongoDB, Caddy, сайт
- **Сервер Б (зарубежье)**: Telegram-бот, SSH-туннель к MongoDB

Серверы соединены через **autossh-туннель**, который автоматически восстанавливается при обрыве связи.

## 🚀 Быстрый старт (локально)

### 1. Клонируйте репозиторий

```bash
git clone https://gitflic.ru/project/piroman99/2mov.git
cd 2mov
```
### 2. Настройте переменные окружения
```bash
cp .env.example .env
# Отредактируйте .env — добавьте токены ботов MAX и Telegram
```
### 3. Запустите через Docker Compose
```bash

docker-compose up -d
```

### 4. Проверьте работу

### 4.1. Убедитесь, что все контейнеры запущены

```bash
docker-compose ps
```

**Ожидаемый результат:** три контейнера (2mov-mongo, 2mov-bot, 2mov-caddy) со статусом Up.

### 4.2. Проверьте сайт-заглушку

```bash
curl -I http://localhost
```

**Ожидаемый результат:** HTTP/1.1 200 OK

Или откройте в браузере: http://localhost

### 4.3. Посмотрите логи бота

```bash
docker-compose logs bot
```

**Ожидаемый результат:**


🚀 2MOV бот запускается...
✅ Подключение к MongoDB установлено
⏳ Обработчики команд в разработке...


### 4.4. Проверьте MongoDB

```bash
docker-compose exec mongo mongosh --eval "db.adminCommand('ping')"
```

**Ожидаемый результат:** { ok: 1 }

### 4.5. Проверьте Caddy

```bash
curl http://localhost | head -n 5
```

**Ожидаемый результат:** первые строки HTML вашего сайта.
