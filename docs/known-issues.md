# Известные проблемы и костыли

## Закрытие чата через 15 секунд после завершения заказа

**Проблема:** Если закрыть чат сразу после завершения заказа, клиент может не получить последнее уведомление.

**Решение:** В `completeOrder` добавлена горутина:
```go
go func() {
    time.Sleep(15 * time.Second)
    db.Collection("chats").UpdateOne(...)
}()
```
**Почему не зависает бот:** `go func()` запускает код в отдельном потоке.
