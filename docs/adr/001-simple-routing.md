# ADR 001: Использование SimpleRouting вместо реального API на старте

## Дата
2026-05-20

## Статус
Принято

## Контекст
Для расчёта цены заказа нужно расстояние между точками.
Реальные API (2ГИС, Яндекс) требуют платной подписки и расходуют демо-ключ.

## Решение
Использовать упрощённый расчёт расстояния по формуле гаверсинуса (расстояние по прямой).

## Последствия

### Плюсы
- Нулевая стоимость на старте
- Мгновенный расчёт без задержек
- Независимость от внешних API

### Минусы
- Погрешность 10–20% по сравнению с реальной дорогой
- Не учитывает дорожную сеть, пробки

## План миграции
При масштабировании заменим реализацию через интерфейс RoutingService.
