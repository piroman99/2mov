# ADR 003: Использование Caddy с разными путями для двух ботов

## Дата
2026-05-20

## Статус
Принято

## Контекст
Оба бота работают на одном сервере. MAX требует уникальный webhook-URL для каждого бота.

## Решение
- Использовать Caddy как reverse proxy
- Клиентский бот: /webhook
- Водительский бот: /webhookd

Caddyfile:
   handle /webhookd* {
       reverse_proxy bot-driver:8080
   }
   handle /webhook* {
       reverse_proxy bot:8080
   }
   handle {
       root * /app/site
       file_server
   }

## Последствия

### Плюсы
- Единый домен для обоих ботов
- Простая маршрутизация

### Минусы
- Порядок handle важен

## Альтернативы, которые не подошли
- Разные поддомены — сложнее с сертификатами
- Один путь для всех ботов — невозможно
