# ADR 002: Разделение на клиентского и водительского ботов

## Дата
2026-05-20

## Статус
Принято

## Контекст
В одном боте совмещены роли клиента и водителя.

## Решение
Создать двух отдельных ботов в MAX:
- 2mov — клиентский бот (создание заказов)
- 2mov-driver — водительский бот (приём заказов)

У каждого бота свой токен и свой webhook-путь:
- Клиент: /webhook
- Водитель: /webhookd

## Последствия

### Плюсы
- Чистое разделение ответственности
- Клиент не видит лишних команд

### Минусы
- Два контейнера вместо одного
- Нужно управлять двумя подписками в MAX

## Связка аккаунтов
В будущем свяжем аккаунты через номер телефона (команда /link).
